# Integração Wear OS

O encaminhamento de apoio do relógio ao celular permanece uma próxima etapa.
Não há artefato `wear` publicado nesta versão. O núcleo `core` pode ser usado
para catálogo, mas o launcher `android` é destinado ao celular.

A implementação deverá abrir uma URL revisada no telefone, apresentar falha
quando ele não estiver disponível e manter o app funcional sem contribuição.
O adaptador precisa ser testado em Wear OS e nas variantes efetivamente distribuídas.
